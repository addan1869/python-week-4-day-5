# Week 4 - Day 5: Linked Lists Basics

## Overview

On Day 5 of Week 4, I learned the fundamentals of **Linked Lists**, one of the most important linear data structures. I implemented linked lists using Python classes and practiced creating nodes, connecting them, traversing the list, inserting new nodes, and searching for elements. This session also helped me understand how linked lists differ from arrays in memory organization and flexibility.

## Topics Covered

- Introduction to Linked Lists
- Structure of a Node
- Creating a Linked List
- Traversing a Linked List
- Inserting Nodes
- Searching for an Element
- Dynamic Memory Allocation
- Linked List vs Array

## Learning Outcomes

After completing today's work, I am able to:

- Explain the concept of a linked list.
- Understand the structure of a node containing data and a reference to the next node.
- Create and connect nodes using Python classes.
- Traverse and display all nodes in a linked list.
- Insert new nodes into a linked list.
- Search for elements in a linked list.
